# 2.4. Введение в сортировки

## Зачем вообще сортировать

Сортировка располагает элементы по выбранному правилу. После неё часто проще:

- выполнять бинарный поиск;
- находить дубликаты;
- объединять несколько наборов данных;
- строить отчёты и интерфейсы;
- применять два указателя;
- искать минимальные, максимальные и соседние значения.

Сортируется не обязательно само число. У объекта выбирается **ключ**.

```python
cities = [
    {"name": "Москва", "population": 13_000_000},
    {"name": "Париж", "population": 2_100_000},
]

ordered = sorted(cities, key=lambda city: city["population"])
```

## Что значит «ключ сортировки»

Ключ — значение, по которому сравниваются элементы.

```python
users = [
    {"name": "Анна", "age": 30},
    {"name": "Илья", "age": 25},
]

by_age = sorted(users, key=lambda user: user["age"])
```

Можно сортировать по составному ключу:

```python
by_age_and_name = sorted(
    users,
    key=lambda user: (user["age"], user["name"]),
)
```

Сначала сравнивается возраст, а при равенстве — имя.

## Устойчивая сортировка

Сортировка устойчива, если элементы с одинаковым ключом сохраняют прежний взаимный порядок.

```text
до сортировки по возрасту:
Анна(30), Борис(25), Вера(30)

после устойчивой сортировки:
Борис(25), Анна(30), Вера(30)
```

Анна осталась раньше Веры.

Устойчивость позволяет сортировать в несколько этапов. Например, сначала по имени, затем стабильной сортировкой по отделу — внутри каждого отдела имена останутся упорядоченными.

Python `sorted()` и `list.sort()` устойчивы.

## In-place и дополнительная память

- **in-place** — алгоритм переставляет элементы в исходной коллекции, используя `O(1)` или небольшую дополнительную память;
- сортировка с копией создаёт новый результат и требует память порядка `O(n)`.

В Python:

```python
items.sort()          # меняет items, возвращает None
ordered = sorted(items)  # создаёт новый список
```

## Сортировка выбором

Идея: на каждой позиции найти минимальный элемент неотсортированной части и поставить его на текущую позицию.

```python
def selection_sort(items):
    for position in range(len(items) - 1):
        minimum_index = position

        for index in range(position + 1, len(items)):
            if items[index] < items[minimum_index]:
                minimum_index = index

        items[position], items[minimum_index] = (
            items[minimum_index],
            items[position],
        )

    return items
```

### Инвариант

Перед каждой итерацией элементы левее `position` уже находятся на окончательных местах.

### Сложность

- лучший, средний и худший случаи — `O(n²)` сравнений;
- обменов — `O(n)`;
- дополнительная память — `O(1)`.

Типичная реализация с обменом **неустойчива**. Например, перемещение найденного минимума может изменить порядок равных элементов. Иногда встречаются устойчивые модификации, но они требуют сдвигов и отличаются от обычного алгоритма.

Сортировка выбором бывает полезна, когда сравнения допустимы, а физические записи или обмены очень дороги: обменов у неё мало.

## Сортировка вставками

Идея: левая часть уже отсортирована. Берём следующий элемент и вставляем его на правильное место, сдвигая большие элементы вправо.

```python
def insertion_sort(items):
    for index in range(1, len(items)):
        current = items[index]
        position = index

        while position > 0 and items[position - 1] > current:
            items[position] = items[position - 1]
            position -= 1

        items[position] = current

    return items
```

### Инвариант

Перед обработкой `items[index]` диапазон `items[:index]` уже отсортирован.

### Сложность

- лучший случай для уже отсортированных данных — `O(n)`;
- средний и худший случаи — `O(n²)`;
- дополнительная память — `O(1)`;
- алгоритм устойчив, потому что равные элементы не перескакивают друг через друга.

Сортировка вставками хороша для маленьких или почти отсортированных массивов. Поэтому её идеи применяются как часть более сложных гибридных сортировок.

## Сортировка пузырьком

Сравниваются соседние элементы. Если они стоят неправильно, они меняются местами. После прохода самый большой из оставшихся элементов «всплывает» вправо.

```python
def bubble_sort(items):
    for right in range(len(items) - 1, 0, -1):
        swapped = False

        for index in range(right):
            if items[index] > items[index + 1]:
                items[index], items[index + 1] = (
                    items[index + 1],
                    items[index],
                )
                swapped = True

        if not swapped:
            break

    return items
```

### Зачем `swapped`

Если за полный проход не было ни одного обмена, массив уже отсортирован и работу можно завершить.

### Сложность

- лучший случай с ранним завершением — `O(n)`;
- средний и худший — `O(n²)`;
- дополнительная память — `O(1)`;
- алгоритм устойчив при обмене только строго неупорядоченных соседей.

На практике пузырьковая сортировка почти всегда проигрывает библиотечной. Её ценность — учебная наглядность.

## Сортировка Шелла

Сортировка вставками медленна, когда маленький элемент находится далеко справа: его приходится перемещать через множество соседей.

Сортировка Шелла сначала сравнивает элементы через большой шаг `gap`, затем уменьшает шаг. Последний проход с `gap = 1` является сортировкой вставками, но массив к этому моменту уже почти упорядочен.

```python
def shell_sort(items):
    gap = len(items) // 2

    while gap > 0:
        for index in range(gap, len(items)):
            current = items[index]
            position = index

            while (
                position >= gap
                and items[position - gap] > current
            ):
                items[position] = items[position - gap]
                position -= gap

            items[position] = current

        gap //= 2

    return items
```

### Особенности

- работает на месте;
- обычно неустойчива;
- скорость сильно зависит от последовательности шагов;
- точная оценка зависит от выбранных `gap`;
- на практике интересна как улучшение вставок, но стандартные библиотечные сортировки обычно предпочтительнее.

Нельзя без уточнения назвать одну универсальную сложность Shell sort: разные последовательности шагов дают разные оценки.

## Сводная таблица

| Алгоритм | Лучший случай | Средний/худший | Память | Устойчивость |
|---|---:|---:|---:|---|
| Выбором | `O(n²)` | `O(n²)` | `O(1)` | обычно нет |
| Вставками | `O(n)` | `O(n²)` | `O(1)` | да |
| Пузырьком | `O(n)` с оптимизацией | `O(n²)` | `O(1)` | да |
| Шелла | зависит от шагов | зависит от шагов | `O(1)` | нет |

## Что использовать в реальном Python

```python
ordered = sorted(items)
items.sort()
```

Преимущества:

- реализация хорошо протестирована и оптимизирована;
- устойчива;
- принимает `key`;
- хорошо работает с частично упорядоченными данными;
- не нужно вручную поддерживать сложный алгоритм.

```python
products.sort(key=lambda product: product.price, reverse=True)
```

Изучение ручных сортировок нужно, чтобы понимать сложность, устойчивость и устройство алгоритмов, а не чтобы заменять `sort()` в приложении.

## JavaScript: важная ловушка

Без функции сравнения числа могут сортироваться как строки:

```javascript
const numbers = [2, 10, 3];

numbers.sort(); // нежелательно для чисел: [10, 2, 3]
numbers.sort((a, b) => a - b); // [2, 3, 10]
```

`Array.prototype.sort()` изменяет исходный массив. Для копии:

```javascript
const ordered = [...numbers].sort((a, b) => a - b);
```

## Когда сортировка не нужна

- нужен только минимум — один проход `O(n)`;
- нужна проверка наличия — возможно, подойдёт `set`;
- нужно несколько наименьших элементов — может подойти куча;
- данные уже поддерживаются в нужном порядке другой структурой;
- сортировка стоит дороже, чем небольшое число линейных поисков.

## Что важно запомнить

1. Всегда определяй ключ и направление сортировки.
2. Устойчивость относится к порядку элементов с равными ключами.
3. Сортировка выбором обычно неустойчива, вставками и пузырьком — устойчивы.
4. Квадратичные сортировки полезны для обучения и специальных маленьких входов.
5. Сложность Shell sort зависит от последовательности шагов.
6. В рабочем Python почти всегда начинай с `sorted()` или `.sort()`.
