# Самопроверка к лекции 2.4

## Вопросы

1. Что называется ключом сортировки?
2. Что сохраняет устойчивая сортировка?
3. Чем `sorted(items)` отличается от `items.sort()`?
4. Почему сортировка выбором всегда выполняет `O(n²)` сравнений?
5. Когда вставки работают за `O(n)`?
6. Зачем пузырьку флаг `swapped`?
7. От чего зависит сложность сортировки Шелла?

## Определи алгоритм

1. Находим минимум справа и ставим на текущую позицию.
2. Берём следующий элемент и вставляем в упорядоченный префикс.
3. Меняем соседей, пока крупные элементы не окажутся справа.
4. Сначала сравниваем элементы через большой шаг.

Ответы: выбором, вставками, пузырьком, Шелла.

## Практика с ключом

Отсортируй задачи сначала по приоритету, затем по названию:

```python
tasks = [
    {"title": "Deploy", "priority": 2},
    {"title": "Backup", "priority": 1},
    {"title": "Audit", "priority": 1},
]

ordered = sorted(
    tasks,
    key=lambda task: (task["priority"], task["title"]),
)
```

## Ответы

1. Значение, извлекаемое из элемента для сравнения и определения порядка.
2. Взаимный порядок элементов с одинаковым ключом.
3. `sorted` возвращает новый список, `.sort()` изменяет исходный и возвращает `None`.
4. Для каждой позиции алгоритм снова просматривает неотсортированный остаток независимо от исходного порядка.
5. Когда массив уже отсортирован или почти отсортирован и сдвигов мало.
6. Чтобы закончить после прохода без обменов.
7. От выбранной последовательности значений `gap`.
