# 4.1. Деревья поиска: устройство, операции и обходы

## Зачем нужны деревья

Массивы и связные списки описывают в основном линейный порядок:

```text
A -> B -> C -> D
```

Дерево описывает иерархию:

```text
        A
      /   \
     B     C
    / \     \
   D   E     F
```

Деревья встречаются в:

- структуре каталогов;
- DOM-дереве веб-страницы;
- синтаксических деревьях программ;
- индексах баз данных;
- маршрутизации;
- системах принятия решений;
- поисковых структурах;
- представлении вложенных комментариев и категорий.

## Основные термины

### Узел

Отдельный элемент дерева. Хранит данные и ссылки на дочерние узлы.

### Корень

Верхний узел дерева. У него нет родителя.

### Родитель и потомок

Если от `A` идёт связь к `B`, то `A` — родитель, `B` — потомок.

### Лист

Узел без потомков.

### Поддерево

Узел вместе со всеми его потомками.

### Глубина

Расстояние от корня до узла.

### Высота

Максимальное расстояние от узла до листа. Высота всего дерева считается от корня.

В разных источниках высоту считают либо в рёбрах, либо в узлах. В этом конспекте считаем рёбра:

- высота листа — `0`;
- высота пустого дерева — `-1`;
- дерево из одного корня имеет высоту `0`.

Важно не конкретное соглашение, а последовательность его использования.

## Что делает структуру деревом

Для обычного корневого дерева выполняются свойства:

- существует один корень;
- у каждого другого узла ровно один родитель;
- циклов нет;
- от корня можно дойти до каждого узла.

Если создать ссылку от потомка обратно к предку, получится цикл, и обычные алгоритмы обхода могут не завершиться.

## Бинарное дерево

Бинарное дерево разрешает каждому узлу не более двух потомков:

- `left` — левый;
- `right` — правый.

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

Слово «бинарное» не означает, что дерево автоматически отсортировано.

## Бинарное дерево поиска

Binary Search Tree, или BST, добавляет правило порядка:

```text
все ключи слева < ключ узла < все ключи справа
```

Для каждого поддерева действует то же правило.

```text
          16
        /    \
      12      18
     /  \    /  \
   11   15  17   21
```

Благодаря этому после сравнения можно отбросить одно из поддеревьев, как половину диапазона в бинарном поиске.

## Что делать с дубликатами

Правило нужно выбрать заранее. Возможные варианты:

- не добавлять повторный ключ;
- хранить счётчик повторений внутри узла;
- договориться, что равные ключи всегда идут только влево или только вправо;
- хранить список значений для одного ключа.

Нельзя одновременно разрешать равные ключи и слева, и справа: поиск и удаление становятся неоднозначными.

В примерах ниже повторная вставка игнорируется.

## Высота определяет стоимость операций

Поиск, вставка и удаление идут по одному пути сверху вниз. Их сложность:

```text
O(h), где h — высота дерева
```

### Сбалансированное дерево

Если поддеревья имеют примерно одинаковую высоту:

```text
h = O(log n)
```

Операции занимают `O(log n)`.

### Вырожденное дерево

Если вставлять уже отсортированные значения в обычное BST:

```text
1
 \
  2
   \
    3
     \
      4
```

дерево превращается почти в связный список:

```text
h = n - 1
```

Операции деградируют до `O(n)`.

Обычное BST само себя не балансирует. AVL-деревья и красно-чёрные деревья используют дополнительные правила, чтобы поддерживать логарифмическую высоту.

## Поиск элемента

```python
def search(root, target):
    current = root

    while current is not None:
        if target == current.value:
            return current

        if target < current.value:
            current = current.left
        else:
            current = current.right

    return None
```

На каждом шаге выбирается только одна ветка.

- время — `O(h)`;
- дополнительная память итеративной версии — `O(1)`.

Рекурсивная версия потребовала бы `O(h)` памяти стека вызовов.

## Минимум и максимум

Минимальный ключ находится в самом левом узле, максимальный — в самом правом.

```python
def minimum_node(root):
    if root is None:
        return None

    current = root

    while current.left is not None:
        current = current.left

    return current


def maximum_node(root):
    if root is None:
        return None

    current = root

    while current.right is not None:
        current = current.right

    return current
```

Обе операции занимают `O(h)`.

## Вставка

Ищем место так же, как значение. Когда нужная ссылка равна `None`, создаём там узел.

```python
def insert(root, value):
    if root is None:
        return Node(value)

    if value < root.value:
        root.left = insert(root.left, value)
    elif value > root.value:
        root.right = insert(root.right, value)

    return root
```

Почему функция возвращает корень:

- пустое поддерево после вставки получает новый корень;
- родитель должен сохранить эту новую ссылку;
- корень всего дерева тоже может появиться при первой вставке.

Использование:

```python
root = None

for value in [16, 12, 18, 11, 15, 17, 21]:
    root = insert(root, value)
```

- время — `O(h)`;
- память рекурсивного стека — `O(h)`.

## Удаление: три случая

Удаление — самая сложная базовая операция BST.

### Случай 1. Лист

У узла нет потомков. Возвращаем `None`, и родитель перестаёт на него ссылаться.

### Случай 2. Один потомок

Удаляемый узел заменяется единственным потомком.

```text
    10                 7
   /       ->         / \
  7                  5   9
 / \
5   9
```

### Случай 3. Два потомка

Нужна замена, сохраняющая порядок BST. Обычно берут:

- минимальный узел правого поддерева — следующий по возрастанию;
- либо максимальный узел левого поддерева — предыдущий по возрастанию.

Значение копируется в удаляемый узел, после чего исходный узел-замена удаляется из своего поддерева.

## Реализация удаления

```python
def delete(root, target):
    if root is None:
        return None

    if target < root.value:
        root.left = delete(root.left, target)
        return root

    if target > root.value:
        root.right = delete(root.right, target)
        return root

    # Узел найден.
    if root.left is None:
        return root.right

    if root.right is None:
        return root.left

    successor = minimum_node(root.right)
    root.value = successor.value
    root.right = delete(root.right, successor.value)
    return root
```

Первые две проверки потомков одновременно покрывают:

- лист — оба потомка `None`, вернётся `None`;
- только правый потомок — вернётся `root.right`;
- только левый потомок — вернётся `root.left`.

Сложность — `O(h)` времени и `O(h)` памяти рекурсивного стека.

## Обход дерева

Обход означает посещение каждого узла по определённому правилу.

Для `n` узлов любой полный обход требует `O(n)` времени: каждый узел нужно обработать хотя бы один раз.

# Обход в ширину

Breadth-First Search/Traversal проходит дерево по уровням:

```text
          16
        /    \
      12      18
     /  \    /  \
   11   15  17   21

результат: 16, 12, 18, 11, 15, 17, 21
```

Используется очередь:

```python
from collections import deque


def breadth_first(root):
    if root is None:
        return []

    result = []
    queue = deque([root])

    while queue:
        node = queue.popleft()
        result.append(node.value)

        if node.left is not None:
            queue.append(node.left)

        if node.right is not None:
            queue.append(node.right)

    return result
```

- время — `O(n)`;
- дополнительная память — `O(w)`, где `w` — максимальная ширина уровня;
- в худшем случае ширина может быть `O(n)`.

Использовать Python `list.pop(0)` не следует: удаление из начала списка стоит `O(n)`.

## Обход в глубину

Depth-First Search/Traversal идёт по ветке до конца, затем возвращается.

Три основных порядка описываются положением `N` — текущего узла:

- `NLR` — preorder: узел, левое, правое;
- `LNR` — inorder: левое, узел, правое;
- `LRN` — postorder: левое, правое, узел.

## Inorder: LNR

```python
def inorder(root, result=None):
    if result is None:
        result = []

    if root is None:
        return result

    inorder(root.left, result)
    result.append(root.value)
    inorder(root.right, result)
    return result
```

Для BST inorder возвращает ключи по возрастанию:

```text
11, 12, 15, 16, 17, 18, 21
```

Именно это свойство связывает BST с отсортированной последовательностью.

## Reverse inorder: RNL

```python
def reverse_inorder(root, result=None):
    if result is None:
        result = []

    if root is None:
        return result

    reverse_inorder(root.right, result)
    result.append(root.value)
    reverse_inorder(root.left, result)
    return result
```

Для BST возвращает ключи по убыванию.

## Preorder: NLR

```python
def preorder(root, result=None):
    if result is None:
        result = []

    if root is None:
        return result

    result.append(root.value)
    preorder(root.left, result)
    preorder(root.right, result)
    return result
```

Preorder полезен, когда родителя нужно обработать раньше потомков: например, для сериализации структуры или копирования дерева.

## Postorder: LRN

```python
def postorder(root, result=None):
    if result is None:
        result = []

    if root is None:
        return result

    postorder(root.left, result)
    postorder(root.right, result)
    result.append(root.value)
    return result
```

Postorder обрабатывает потомков раньше родителя. Это удобно при удалении дерева, вычислении размеров поддеревьев и обработке выражений.

## Память рекурсивного DFS

- время полного обхода — `O(n)`;
- стек вызовов — `O(h)`;
- для сбалансированного дерева — `O(log n)`;
- для вырожденного — `O(n)`.

В Python глубокое вырожденное дерево может привести к `RecursionError`. Тогда обход реализуют собственным стеком.

## Итеративный inorder

```python
def inorder_iterative(root):
    result = []
    stack = []
    current = root

    while current is not None or stack:
        while current is not None:
            stack.append(current)
            current = current.left

        current = stack.pop()
        result.append(current.value)
        current = current.right

    return result
```

Собственный стек делает скрытую работу рекурсии явной.

## BST против хеш-таблицы

| Требование | BST | `dict` / `set` |
|---|---:|---:|
| Точное получение ключа | `O(h)` | в среднем `O(1)` |
| Минимум/максимум | `O(h)` | обычно `O(n)` |
| Ключи в порядке | inorder `O(n)` | требуется сортировка |
| Диапазон ключей | естественная операция | нет порядка |
| Следующий больший ключ | естественно | напрямую нет |

Хеш-таблица лучше для точного доступа. Упорядоченное дерево — для порядка, диапазонов и соседних значений.

## Что использовать в Python

В стандартной библиотеке Python нет встроенного общего `TreeMap` или `TreeSet`.

В зависимости от задачи используются:

- `dict` / `set` для быстрого точного поиска;
- отсортированный `list` и модуль `bisect` для небольших изменяемых наборов;
- `heapq` для доступа к минимуму;
- база данных с индексом для больших хранимых наборов;
- специализированная библиотека для сбалансированных деревьев.

Самописное несбалансированное BST подходит для обучения, но не является универсальной заменой библиотечным коллекциям.

## Частые ошибки

1. Считать любое бинарное дерево деревом поиска.
2. Обещать `O(log n)` без гарантии балансировки.
3. Не определить политику дубликатов.
4. При вставке или удалении забыть присвоить возвращённый корень поддерева.
5. Удалять узел с двумя потомками без сохранения порядка.
6. Использовать очередь на `list.pop(0)`.
7. Считать полный обход логарифмическим: он посещает все `n` узлов.
8. Не учитывать глубину рекурсии вырожденного дерева.

## Что важно запомнить

1. Стоимость основных операций BST равна `O(h)`, а не автоматически `O(log n)`.
2. Сбалансированное дерево имеет логарифмическую высоту, вырожденное — линейную.
3. Inorder-обход BST возвращает ключи по возрастанию.
4. BFS использует очередь, DFS — стек вызовов или явный стек.
5. Удаление имеет три случая: лист, один потомок, два потомка.
6. Дерево поиска особенно полезно, когда важен порядок ключей.
