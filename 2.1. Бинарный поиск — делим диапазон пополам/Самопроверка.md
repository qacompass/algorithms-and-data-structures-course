# Самопроверка к лекции 2.1

## Вопросы

1. Почему бинарный поиск нельзя применять к произвольному неотсортированному списку?
2. Что означает диапазон `[left, right]`?
3. Почему после сравнения используется `middle + 1` или `middle - 1`?
4. Какова сложность бинарного поиска по времени и памяти в итеративной версии?
5. Чем `lower_bound` отличается от обычного поиска?
6. Что вернёт `lower_bound`, если все элементы меньше `target`?

## Проследи поиск

Для массива:

```python
items = [1, 3, 4, 7, 8, 9, 11, 12, 16, 21, 36]
```

вручную найди `7`. Для каждой итерации запиши `left`, `right`, `middle` и `items[middle]`.

## Найди ошибки

```python
def broken_search(items, target):
    left = 0
    right = len(items) - 1

    while left < right:
        middle = (left + right) // 2

        if items[middle] == target:
            return middle
        if items[middle] < target:
            left = middle
        else:
            right = middle

    return -1
```

Проблемы:

- при двух соседних элементах `middle` может совпасть с `left`, после чего граница не изменится;
- включительный последний элемент может остаться непроверенным;
- схема границ смешана.

## Практика

Напиши функцию, которая возвращает диапазон индексов всех вхождений:

```python
def occurrence_range(items, target):
    first = lower_bound(items, target)
    after_last = upper_bound(items, target)

    if first == after_last:
        return None

    return first, after_last - 1
```

```python
items = [1, 2, 2, 2, 5]
occurrence_range(items, 2)  # (1, 3)
occurrence_range(items, 4)  # None
```

## Ответы

1. Сравнение с серединой не позволяет определить, в какой половине находится значение, если порядок отсутствует.
2. Оба индекса входят в текущую область поиска.
3. Середина уже проверена и должна быть исключена; иначе диапазон может перестать уменьшаться.
4. `O(log n)` времени и `O(1)` дополнительной памяти.
5. Он ищет первую допустимую позицию, где элемент не меньше цели, даже если точного значения нет.
6. `len(items)`, то есть позицию сразу после массива.
