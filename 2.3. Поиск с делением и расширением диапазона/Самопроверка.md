# Самопроверка к лекции 2.3

## Вопросы

1. На сколько частей делит диапазон тернарный поиск?
2. Почему `O(log₃ n)` и `O(log₂ n)` записываются как один класс `O(log n)`?
3. Почему тернарный поиск не обязательно быстрее бинарного?
4. Зачем экспоненциальный поиск удваивает границу?
5. От чего зависит его сложность `O(log m)`?
6. Как экспоненциальное расширение помогает бинарному поиску по ответу?

## Проследи границы

Есть отсортированный массив, а `target` находится на индексе 13. Какие значения примет `border`, начиная с 1?

```text
1 -> 2 -> 4 -> 8 -> 16
```

После этого бинарный поиск выполняется примерно в диапазоне индексов `[8, 16]` с учётом длины массива.

## Практика

Напиши функцию, которая находит только правую границу для монотонного предиката, если заранее она неизвестна:

```python
def find_upper_bound(predicate):
    right = 1

    while not predicate(right):
        right *= 2

    return right
```

После этого первый подходящий ответ лежит в `[0, right]`.

## Ответы

1. На три.
2. Логарифмы с разными основаниями отличаются постоянным множителем, который Big O отбрасывает.
3. На одной итерации приходится выполнять больше сравнений, а реализация сложнее.
4. Чтобы быстро найти участок, в котором может находиться цель.
5. От примерного индекса искомого элемента, а не обязательно от полной длины массива.
6. Оно находит значение, которое точно подходит, то есть безопасную правую границу для дальнейшего поиска.
