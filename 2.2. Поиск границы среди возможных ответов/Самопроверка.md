# Самопроверка к лекции 2.2

## Вопросы

1. Что означает монотонный предикат?
2. Какой предикат используется для целого квадратного корня?
3. Почему подходящая доска большей стороны тоже подходит?
4. Почему одной проверки общей площади дипломов недостаточно?
5. Зачем в задаче с ксероксами отдельно учитывать первую копию?
6. Что должна гарантировать правая граница при поиске первого `True`?

## Определи, можно ли применить бинарный поиск

1. Минимальная скорость, при которой машина успеет произвести заказ к сроку.
2. Первый день, когда накопленная сумма станет не меньше цели.
3. Поиск числа в неотсортированном массиве по сравнению с серединой.
4. Минимальная вместимость грузовика, позволяющая перевезти груз за `k` поездок.

Ответ: в 1, 2 и 4 есть естественный монотонный предикат; в 3 порядок отсутствует.

## Практика

Найди минимальную скорость чтения, позволяющую прочитать все книги за `hours`. Книга не делится между часами, но за час можно прочитать до `speed` страниц одной книги.

```python
def minimum_reading_speed(books, hours):
    if not books:
        return 0

    left = 1
    right = max(books)

    while left < right:
        middle = left + (right - left) // 2
        required_hours = sum(
            (pages + middle - 1) // middle
            for pages in books
        )

        if required_hours <= hours:
            right = middle
        else:
            left = middle + 1

    return left
```

Выражение `(pages + speed - 1) // speed` выполняет целочисленное округление вверх.

## Ответы

1. После некоторой границы результат проверки меняется один раз и больше не возвращается к прежнему значению.
2. `middle * middle <= number`.
3. Увеличение стороны не уменьшает число доступных строк и столбцов.
4. Прямоугольники должны помещаться целиком; достаточная площадь не гарантирует подходящие размеры сетки.
5. До неё существует только один лист, поэтому одновременно запустить оба аппарата нельзя.
6. Она должна точно находиться в допустимой области, иначе искомого `True` внутри диапазона может не быть.
