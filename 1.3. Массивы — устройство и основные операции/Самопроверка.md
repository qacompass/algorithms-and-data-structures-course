# Самопроверка к лекции 1.3

## Вопросы

1. Почему Python `list` может содержать объекты разных типов, хотя классический массив — нет?
2. Чем `size` отличается от `capacity`?
3. Почему `items[500]` имеет сложность `O(1)`?
4. Почему `items.insert(0, value)` имеет сложность `O(n)`?
5. Что означает «два указателя» в Python-задаче?
6. Почему решение `two_sum_sorted` требует отсортированного списка?
7. Чем `items.reverse()` отличается от `items[::-1]`?

## Проследи алгоритм вручную

Для списка:

```python
numbers = [2, 4, 7, 9, 11, 16, 21]
target = 19
```

Запиши для каждого шага:

- `left`;
- `right`;
- выбранные значения;
- их сумму;
- какой указатель нужно сдвинуть.

## Практика

Напиши функцию, которая проверяет, является ли строка палиндромом. Используй два индекса и не создавай перевёрнутую копию строки.

Примеры:

```text
"level" -> True
"python" -> False
```

Возможное решение:

```python
def is_palindrome(text):
    left = 0
    right = len(text) - 1

    while left < right:
        if text[left] != text[right]:
            return False

        left += 1
        right -= 1

    return True
```

- время — `O(n)`;
- дополнительная память — `O(1)`.

## Ответы

1. Внутренний динамический массив Python хранит ссылки одинакового размера, а не сами разнотипные объекты рядом друг с другом.
2. `size` — текущее количество элементов, `capacity` — число мест в уже выделенной области.
3. Позицию ячейки можно вычислить напрямую по начальному адресу и индексу; перебирать предыдущие элементы не нужно.
4. Существующие элементы нужно сдвинуть вправо, чтобы освободить начало.
5. Обычно две переменные с индексами, которые перемещаются по коллекции.
6. Решение принимает решение о движении на основании того, меньше или больше текущая сумма цели. Это надёжно только при упорядоченных значениях.
7. `reverse()` меняет исходный список и возвращает `None`; срез `[::-1]` создаёт новый список.
