# 4.3. Практические задачи на бинарные деревья

## Что тренируем

В этой теме дерево уже не просто структура с операциями `insert` и `search`. Мы учимся выбирать подходящий способ обхода под условие задачи.

Разбираются четыре задачи:

1. построить бинарное дерево из массива;
2. проверить зеркальную симметрию;
3. найти минимальную глубину;
4. сравнить два дерева.

Главный вопрос перед решением:

```text
Нужно обработать отдельные узлы, пары узлов, уровни или целые поддеревья?
```

От ответа зависит выбор между DFS, BFS и прямой работой с индексами.

## Базовый узел

```python
class TreeNode:
    def __init__(self, value, left=None, right=None):
        self.value = value
        self.left = left
        self.right = right
```

В этой лекции рассматриваются обычные бинарные деревья. Они не обязаны соблюдать правило бинарного дерева поиска.

# Задача 1. Построение дерева из массива

## Как массив представляет почти полное дерево

Если узлы записаны по уровням слева направо, для индекса `i`:

```python
left_index = 2 * i + 1
right_index = 2 * i + 2
```

Пример:

```python
values = [8, 9, 11, 7, 16, 3, 1]
```

```text
          8              index 0
        /   \
       9     11          index 1, 2
      / \   / \
     7  16 3   1         index 3, 4, 5, 6
```

Это те же формулы, что используются для хранения двоичной кучи.

## Рекурсивное построение

```python
def build_complete_tree(values, index=0):
    if index >= len(values):
        return None

    root = TreeNode(values[index])
    root.left = build_complete_tree(values, 2 * index + 1)
    root.right = build_complete_tree(values, 2 * index + 2)
    return root
```

Сложность:

- время — `O(n)`;
- память новых узлов — `O(n)`;
- стек рекурсии для почти полного дерева — `O(log n)`.

## Что означает такое построение

Алгоритм **не вставляет значения по правилам BST**. Он только восстанавливает форму дерева по позициям массива.

```python
values = [10, 100, 1]
```

создаст:

```text
    10
   /  \
 100   1
```

Это бинарное дерево, но не бинарное дерево поиска.

## Пустые позиции в массиве

Для неполного дерева часто используют `None`:

```python
values = [1, 2, 3, None, 4]
```

```python
def build_tree_with_gaps(values, index=0):
    if index >= len(values) or values[index] is None:
        return None

    root = TreeNode(values[index])
    root.left = build_tree_with_gaps(values, 2 * index + 1)
    root.right = build_tree_with_gaps(values, 2 * index + 2)
    return root
```

Здесь массив использует **фиксированные индексы полного дерева**. Потомки позиции с `None` недостижимы и тоже не попадут в дерево.

Это отличается от компактной LeetCode-подобной записи по очереди, где следующие значения назначаются только существующим родителям. Формат входа всегда нужно уточнять.

## Итеративное построение по фиксированным индексам

```python
def build_tree_iterative(values):
    if not values or values[0] is None:
        return None

    nodes = [
        None if value is None else TreeNode(value)
        for value in values
    ]

    for index, node in enumerate(nodes):
        if node is None:
            continue

        left_index = 2 * index + 1
        right_index = 2 * index + 2

        if left_index < len(nodes):
            node.left = nodes[left_index]

        if right_index < len(nodes):
            node.right = nodes[right_index]

    return nodes[0]
```

Итеративная версия не использует стек рекурсии, но создаёт дополнительный массив ссылок на узлы.

# Задача 2. Симметричное дерево

## Что означает симметрия

Дерево симметрично относительно вертикальной оси, если:

- значения левого и правого корней совпадают;
- внешняя ветка слева зеркальна внешней ветке справа;
- внутренняя ветка слева зеркальна внутренней ветке справа;
- отсутствующие узлы расположены зеркально.

```text
          1
        /   \
       2     2
      / \   / \
     3   4 4   3
```

Нужно сравнивать **пары зеркальных узлов**, а не просто последовательность значений.

## Рекурсивная проверка зеркальности

```python
def is_mirror(left, right):
    if left is None and right is None:
        return True

    if left is None or right is None:
        return False

    return (
        left.value == right.value
        and is_mirror(left.left, right.right)
        and is_mirror(left.right, right.left)
    )


def is_symmetric(root):
    if root is None:
        return True

    return is_mirror(root.left, root.right)
```

Обрати внимание на перекрёстное сравнение:

```text
left.left  <-> right.right
left.right <-> right.left
```

- время — `O(n)`;
- стек — `O(h)`.

## Итеративная проверка через очередь пар

```python
from collections import deque


def is_symmetric_bfs(root):
    if root is None:
        return True

    pairs = deque([(root.left, root.right)])

    while pairs:
        left, right = pairs.popleft()

        if left is None and right is None:
            continue

        if left is None or right is None:
            return False

        if left.value != right.value:
            return False

        pairs.append((left.left, right.right))
        pairs.append((left.right, right.left))

    return True
```

В очередь обязательно попадают и отсутствующие узлы. Без них два дерева с одинаковыми значениями, но разной структурой можно ошибочно признать симметричными.

## Почему палиндромный inorder недостаточен

Можно получить палиндромную последовательность значений из несимметричного дерева.

```text
      1
     / \
    2   2
     \   \
      2   2
```

Его inorder:

```text
[2, 2, 1, 2, 2]
```

Последовательность является палиндромом, но дерево несимметрично: обе нижние ветви направлены вправо. Сам по себе список значений не кодирует расположение `None`. Даже совпадающие обходы разных деревьев не гарантируют одинаковую форму.

Надёжное решение сравнивает структуру и значения зеркальных узлов одновременно.

# Задача 3. Минимальная глубина

## Определение

Минимальная глубина — количество узлов в кратчайшем пути от корня до **ближайшего листа**.

Лист — узел, у которого нет ни левого, ни правого потомка.

```text
          11            глубина 1
        /    \
       8      16         глубина 2
      / \    / \
     2   7  6   9        глубина 3

минимальная глубина = 3
```

## Почему `1 + min(left, right)` может ошибаться

```text
    1
     \
      2
       \
        3
```

У корня левое поддерево пустое и имеет глубину `0`. Наивная формула вернёт:

```text
1 + min(0, 2) = 1
```

Но корень не является листом. Реальный путь до листа содержит три узла.

Если одно поддерево отсутствует, нужно продолжать по существующему.

## DFS-решение

```python
def minimum_depth(root):
    if root is None:
        return 0

    if root.left is None:
        return 1 + minimum_depth(root.right)

    if root.right is None:
        return 1 + minimum_depth(root.left)

    return 1 + min(
        minimum_depth(root.left),
        minimum_depth(root.right),
    )
```

- время — `O(n)` в худшем случае;
- стек — `O(h)`.

## BFS-решение

BFS идёт по уровням. Первый найденный лист гарантированно находится на минимальной глубине, поэтому обход можно завершить сразу.

```python
from collections import deque


def minimum_depth_bfs(root):
    if root is None:
        return 0

    queue = deque([(root, 1)])

    while queue:
        node, depth = queue.popleft()

        if node.left is None and node.right is None:
            return depth

        if node.left is not None:
            queue.append((node.left, depth + 1))

        if node.right is not None:
            queue.append((node.right, depth + 1))

    raise RuntimeError("unreachable for a finite tree")
```

BFS часто предпочтительнее именно для минимальной глубины: не обязательно посещать узлы ниже первого близкого листа.

Память BFS — `O(w)`, где `w` — максимальная ширина просмотренной части дерева.

# Задача 4. Сравнение двух деревьев

## Что значит «одинаковые»

Два дерева одинаковы, если:

- соответствующие узлы имеют равные значения;
- отсутствующие узлы находятся на одинаковых местах;
- левые поддеревья одинаковы;
- правые поддеревья одинаковы.

Одинаковый набор значений недостаточен.

```text
    1          1
   /            \
  2              2
```

Оба дерева содержат `1` и `2`, но имеют разную структуру.

## Рекурсивное сравнение

```python
def same_tree(first, second):
    if first is None and second is None:
        return True

    if first is None or second is None:
        return False

    return (
        first.value == second.value
        and same_tree(first.left, second.left)
        and same_tree(first.right, second.right)
    )
```

- время — `O(n)` для одинаковых деревьев из `n` узлов;
- при раннем различии функция завершится быстрее;
- стек — `O(h)`.

## Итеративное сравнение

```python
from collections import deque


def same_tree_bfs(first, second):
    pairs = deque([(first, second)])

    while pairs:
        left, right = pairs.popleft()

        if left is None and right is None:
            continue

        if left is None or right is None:
            return False

        if left.value != right.value:
            return False

        pairs.append((left.left, right.left))
        pairs.append((left.right, right.right))

    return True
```

Симметрия и равенство очень похожи, но пары формируются по-разному:

```text
равенство:   left.left  <-> right.left
             left.right <-> right.right

симметрия:   left.left  <-> right.right
             left.right <-> right.left
```

## Почему одного обхода недостаточно

Если сохранить только значения, разные формы могут дать одинаковый результат некоторых обходов.

Для однозначной сериализации нужно хранить маркеры пустых детей:

```python
def serialize_preorder(root, result=None):
    if result is None:
        result = []

    if root is None:
        result.append(None)
        return result

    result.append(root.value)
    serialize_preorder(root.left, result)
    serialize_preorder(root.right, result)
    return result
```

```text
    1              1
   /                \
  2                  2

[1, 2, None, None, None]
[1, None, 2, None, None]
```

Маркеры `None` сохраняют структуру.

## Как выбирать BFS или DFS

### DFS удобен, если

- решение естественно выражается через поддеревья;
- нужно сравнить соответствующие ветви;
- требуется preorder, inorder или postorder;
- важен компактный рекурсивный код;
- дерево не слишком глубокое.

### BFS удобен, если

- ответ связан с ближайшим уровнем;
- нужно остановиться на первом подходящем узле по глубине;
- требуется обработка дерева уровень за уровнем;
- рекурсию использовать нежелательно.

## Частые ошибки

1. Считать построенное по индексам дерево бинарным деревом поиска.
2. Не уточнить формат `None` в массивном представлении.
3. Проверять симметрию только по палиндромности значений обхода.
4. Не учитывать отсутствующие зеркальные узлы.
5. Вычислять минимальную глубину через обычный `min`, когда одно поддерево пустое.
6. Путать ближайший `None` с ближайшим листом.
7. При сравнении деревьев проверять только значения, но не структуру.
8. Сериализовать дерево без маркеров пустых детей.

## Что важно запомнить

1. Формулы `2*i+1` и `2*i+2` восстанавливают форму дерева, а не свойства BST.
2. Симметрия проверяется попарным зеркальным сравнением узлов.
3. Структура дерева так же важна, как значения.
4. Для минимальной глубины BFS может остановиться на первом листе.
5. Если у узла только один потомок, пустую сторону нельзя выбирать как кратчайший путь.
6. Рекурсивные решения часто кратки, но используют `O(h)` памяти стека.
