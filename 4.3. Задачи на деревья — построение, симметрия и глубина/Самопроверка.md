# Самопроверка к занятию 4.3

## Вопросы

1. Что именно восстанавливает функция построения дерева по индексам массива?
2. Почему полученное дерево не обязательно является BST?
3. Какие пары потомков сравниваются при проверке симметрии?
4. Почему палиндром значений inorder не является достаточным доказательством симметрии?
5. Что считается листом?
6. Почему наивная формула минимальной глубины ошибается при одном потомке?
7. Чем сравнение одинаковых деревьев отличается от проверки зеркальности?

## Построй дерево из массива

```python
values = [5, 3, 8, 1, 4, None, 9]
```

При фиксированной индексной схеме получится:

```text
        5
      /   \
     3     8
    / \     \
   1   4     9
```

## Найди минимальную глубину

```text
    1
   /
  2
 /
3
```

Минимальная глубина равна `3`, а не `1`: единственный лист — узел `3`.

## Практика 1. Максимальная глубина

В отличие от минимальной глубины, здесь обычный `max` безопасен:

```python
def maximum_depth(root):
    if root is None:
        return 0

    return 1 + max(
        maximum_depth(root.left),
        maximum_depth(root.right),
    )
```

Пустая сторона не может ошибочно уменьшить максимум.

## Практика 2. Посчитать листья

```python
def count_leaves(root):
    if root is None:
        return 0

    if root.left is None and root.right is None:
        return 1

    return count_leaves(root.left) + count_leaves(root.right)
```

## Практика 3. Инвертировать дерево

```python
def invert_tree(root):
    if root is None:
        return None

    root.left, root.right = (
        invert_tree(root.right),
        invert_tree(root.left),
    )
    return root
```

После инверсии левое и правое поддеревья каждого узла меняются местами.

## Ответы

1. Иерархические связи узлов в почти полном дереве согласно индексам.
2. Значения размещаются по позициям, а не сравнением ключей.
3. `left.left` с `right.right`, а `left.right` с `right.left`.
4. Последовательность без маркеров `None` может потерять информацию о форме дерева.
5. Узел, у которого отсутствуют оба потомка.
6. Нулевая глубина отсутствующей стороны не ведёт к листу, поэтому её нельзя выбирать через `min`.
7. При равенстве сравниваются одноимённые стороны, при симметрии — перекрёстные зеркальные стороны.
