## Практика 1. Первый уникальный символ

Верни индекс первого символа, который встречается ровно один раз:

```python
from collections import Counter


def first_unique_index(text):
    counts = Counter(text)

    for index, character in enumerate(text):
        if counts[character] == 1:
            return index

    return -1
```

Почему нужны два прохода? Первый узнаёт итоговые частоты, второй сохраняет порядок строки и находит первый подходящий индекс.

## Практика 2. Сгруппировать числа по остатку

```python
def group_by_remainder(numbers, divisor):
    if divisor <= 0:
        raise ValueError("divisor must be positive")

    groups = {}

    for number in numbers:
        key = number % divisor
        groups.setdefault(key, []).append(number)

    return groups
```

Здесь канонический ключ — остаток от деления.

## Практика 3. Накормить животных

Определи результат:

```python
animals = [1, 2, 2]
food = [7, 1]
```

После сортировки:

```text
animals = [1, 2, 2]
food    = [1, 7]
```

Порция `1` кормит первое животное, `7` — второе. Ответ: `2`.

## Ответы

1. Количество каждого символа, оставшееся после вычитания символов исходной строки.
2. Множество хранит только наличие и теряет количество повторений.
3. Чтобы словарь содержал только предыдущие элементы и один индекс нельзя было использовать дважды.
4. `O(n)` времени и `O(n)` дополнительной памяти в среднем.
5. Тогда маленькие порции можно безопасно отдавать животным с маленькими потребностями, не расходуя крупные порции зря.
6. Одинаковое нормализованное представление для всех элементов одной группы.
7. Список изменяем и не хешируется, а неизменяемый кортеж можно использовать как ключ `dict`.
