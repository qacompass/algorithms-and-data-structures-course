## Проследи операции

```python
from collections import deque

items = deque()
items.append(10)
items.append(20)
items.appendleft(5)
a = items.pop()
items.append(30)
b = items.popleft()
```

Ответь:

- чему равно `a`;
- чему равно `b`;
- что осталось в `items`.

## Практика 1: стек с минимумом

Реализуй стек, который умеет возвращать минимальный элемент за `O(1)`. Используй второй стек для текущих минимумов.

```python
class MinStack:
    def __init__(self):
        self.values = []
        self.minimums = []

    def push(self, value):
        self.values.append(value)

        if not self.minimums or value <= self.minimums[-1]:
            self.minimums.append(value)

    def pop(self):
        if not self.values:
            raise IndexError("pop from empty stack")

        value = self.values.pop()

        if value == self.minimums[-1]:
            self.minimums.pop()

        return value

    def get_min(self):
        if not self.minimums:
            raise IndexError("minimum of empty stack")

        return self.minimums[-1]
```

Подумай, зачем используется условие `value <= self.minimums[-1]`, а не только `<`.

## Практика 2: очередь задач

```python
from collections import deque


def process_tasks(tasks):
    queue = deque(tasks)
    result = []

    while queue:
        task = queue.popleft()
        result.append(f"done: {task}")

    return result
```

Определи сложность по времени и дополнительной памяти относительно числа задач `n`.

## Практика 3: последние N событий

`deque` может автоматически выбрасывать самые старые элементы:

```python
from collections import deque

last_events = deque(maxlen=3)

last_events.append("login")
last_events.append("open page")
last_events.append("click")
last_events.append("logout")

print(list(last_events))
```

Результат:

```python
["open page", "click", "logout"]
```

Это удобно для скользящего окна, последних логов или истории ограниченного размера.

## Ответы

1. LIFO извлекает последний добавленный элемент, FIFO — первый добавленный.
2. `C`, `B`, `A`.
3. `A`, `B`, `C`.
4. После удаления остальные ссылки сдвигаются к началу, поэтому операция занимает `O(n)`.
5. Добавление и удаление с левого и правого концов: `append`, `appendleft`, `pop`, `popleft`.
6. Они отмечают позицию извлечения и позицию следующей вставки, поэтому элементы не приходится сдвигать.
7. `head == tail` может означать как пустое, так и полное состояние; `size` устраняет неоднозначность.
8. Они уменьшают количество особых случаев для пустой структуры и операций у краёв.

В задании с `deque`: `a == 20`, `b == 5`, в `items` остаются `[10, 30]`.

Для `process_tasks` время — `O(n)`, дополнительная память — `O(n)` для очереди и результата.

В `MinStack` условие `<=` нужно для повторяющихся минимумов. Если дважды добавить одинаковый минимум, после удаления одного второй всё ещё должен считаться текущим минимумом.
