# 1.6. Стек, очередь и дек

## Самая короткая версия

Стек, очередь и дек отличаются прежде всего **правилом добавления и извлечения элементов**.

| Структура | Правило | Добавляем | Извлекаем |
|---|---|---|---|
| Стек | LIFO: последний вошёл — первый вышел | с вершины | с вершины |
| Очередь | FIFO: первый вошёл — первый вышел | в конец | из начала |
| Дек | Двусторонняя очередь | с любого конца | с любого конца |

Это абстрактные структуры данных. Их можно реализовать массивом, связным списком или другой внутренней структурой. Пользователю стека не обязательно знать, как он устроен внутри, если операции соблюдают нужные правила.

## Термины операций

Обычно используют следующие названия:

### Стек

- `push` — положить на вершину;
- `pop` — снять с вершины;
- `peek` или `top` — посмотреть вершину без удаления.

### Очередь

- `enqueue` — добавить в конец;
- `dequeue` — извлечь из начала;
- `front` — посмотреть первый элемент.

### Дек

- `append` / `push_back` — добавить справа;
- `appendleft` / `push_front` — добавить слева;
- `pop` / `pop_back` — извлечь справа;
- `popleft` / `pop_front` — извлечь слева.

Названия в библиотеках могут отличаться, но правило поведения важнее названия.

# Стек

## Как он работает

Стек похож на стопку тарелок: новую кладут сверху и верхнюю же забирают первой.

```text
push A       push B       push C       pop -> C

[A]         [B]          [C]          [B]
            [A]          [B]          [A]
                         [A]
```

Последовательность извлечения будет обратной последовательности добавления.

## Стек на Python list

Для большинства Python-задач отдельный класс не нужен:

```python
stack = []

stack.append("A")  # push
stack.append("B")
stack.append("C")

top = stack[-1]    # peek: "C"
value = stack.pop()  # pop: "C"
```

- `append()` — амортизированно `O(1)`;
- `pop()` с конца — `O(1)`;
- `stack[-1]` — `O(1)`.

Важно использовать конец списка. `insert(0, value)` и `pop(0)` требуют сдвигать элементы и имеют `O(n)`.

## Стек на JavaScript Array

```javascript
const stack = [];

stack.push("A");
stack.push("B");
stack.push("C");

const top = stack.at(-1);
const value = stack.pop();
```

`push()` и `pop()` с конца массива обычно имеют амортизированное `O(1)`.

## Где используется стек

- история действий и `Ctrl+Z`;
- переходы «Назад» в браузере;
- стек вызовов функций;
- рекурсия;
- проверка правильности скобок;
- обход графа в глубину;
- вычисление выражений;
- парсеры языков и форматов;
- алгоритм возврата назад (`backtracking`).

## Пример: правильные скобки

```python
def is_balanced(text):
    pairs = {
        ")": "(",
        "]": "[",
        "}": "{",
    }
    stack = []

    for character in text:
        if character in "([{":
            stack.append(character)
        elif character in pairs:
            if not stack or stack.pop() != pairs[character]:
                return False

    return not stack
```

Почему стек подходит: последняя открытая скобка должна закрыться первой.

- время — `O(n)`;
- дополнительная память — `O(n)` в худшем случае.

## Стек вызовов и рекурсия

При вызове функции интерпретатор сохраняет информацию о текущем выполнении: локальные переменные, место возврата и другие данные. Новый вызов помещается поверх предыдущего.

```python
def countdown(number):
    if number == 0:
        return

    countdown(number - 1)
```

Для большого `number` создаётся много кадров стека. В Python глубина рекурсии ограничена, поэтому рекурсивная запись не всегда практичнее цикла.

## Стек на связном списке

Вершиной удобно сделать `head`:

```python
class StackNode:
    def __init__(self, data, next_node=None):
        self.data = data
        self.next = next_node


class LinkedStack:
    def __init__(self):
        self.top = None

    def push(self, data):
        self.top = StackNode(data, self.top)

    def pop(self):
        if self.top is None:
            raise IndexError("pop from empty stack")

        value = self.top.data
        self.top = self.top.next
        return value
```

Обе операции меняют только вершину и имеют `O(1)`.

# Очередь

## Как она работает

Очередь похожа на очередь к кассе: первый пришедший обслуживается первым.

```text
front                         back
  |                             |
  v                             v
[A] <- извлечём первым    [B] [C] <- добавляем сюда
```

## Правильный выбор в Python: collections.deque

```python
from collections import deque

queue = deque()

queue.append("A")    # enqueue
queue.append("B")
queue.append("C")

value = queue.popleft()  # dequeue: "A"
```

`append()` и `popleft()` имеют `O(1)`.

Не стоит реализовывать большую очередь так:

```python
queue = []
queue.append(value)
first = queue.pop(0)  # O(n): остальные элементы сдвигаются
```

## Очередь на JavaScript

Наивный вариант с `shift()` прост, но удаление из начала большого массива может стоить `O(n)`:

```javascript
const queue = [];
queue.push("A");
queue.push("B");
const value = queue.shift();
```

Для небольшой интерфейсной очереди это может быть приемлемо. Для большого потока лучше хранить индекс головы:

```javascript
class Queue {
  constructor() {
    this.items = [];
    this.head = 0;
  }

  enqueue(value) {
    this.items.push(value);
  }

  dequeue() {
    if (this.head >= this.items.length) {
      return undefined;
    }

    const value = this.items[this.head];
    this.items[this.head] = undefined;
    this.head += 1;
    return value;
  }
}
```

В полноценной реализации нужно иногда уплотнять массив, чтобы освобождать накопившуюся неиспользуемую часть.

## Очередь на связном списке

Храним две ссылки:

- `head` — откуда извлекаем;
- `tail` — куда добавляем.

```python
class QueueNode:
    def __init__(self, data):
        self.data = data
        self.next = None


class LinkedQueue:
    def __init__(self):
        self.head = None
        self.tail = None

    def enqueue(self, data):
        node = QueueNode(data)

        if self.tail is None:
            self.head = node
            self.tail = node
        else:
            self.tail.next = node
            self.tail = node

    def dequeue(self):
        if self.head is None:
            raise IndexError("dequeue from empty queue")

        value = self.head.data
        self.head = self.head.next

        if self.head is None:
            self.tail = None

        return value
```

Добавление и извлечение имеют `O(1)`. При удалении последнего элемента важно сбросить и `tail`, иначе очередь останется в некорректном состоянии.

## Где используется очередь

- задания фонового обработчика;
- очередь сообщений;
- печать документов;
- обработка запросов;
- планирование процессов;
- обход графа в ширину;
- события пользовательского интерфейса;
- ограничение количества одновременно выполняемых задач.

## Пример: обработка задач

```python
from collections import deque

tasks = deque(["resize image", "send email", "build report"])

while tasks:
    task = tasks.popleft()
    print(f"Processing: {task}")
```

Задачи обрабатываются в порядке поступления.

## Кольцевой буфер

Обычный массив можно использовать как очередь без сдвига элементов. Для этого хранят индексы `head` и `tail`, которые после конца массива возвращаются к началу.

```text
индексы:  0    1    2    3    4
         [D]  [E]  [_]  [B]  [C]
                    ^    ^
                  tail  head
```

Переход к следующей позиции вычисляют через остаток от деления:

```python
index = (index + 1) % capacity
```

Элементы не нужно каждый раз сдвигать к нулевой ячейке. Поэтому добавление и извлечение остаются `O(1)`.

### Упрощённый кольцевой буфер фиксированной ёмкости

```python
class RingBuffer:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError("capacity must be positive")

        self.data = [None] * capacity
        self.capacity = capacity
        self.head = 0
        self.tail = 0
        self.size = 0

    def enqueue(self, value):
        if self.size == self.capacity:
            raise OverflowError("buffer is full")

        self.data[self.tail] = value
        self.tail = (self.tail + 1) % self.capacity
        self.size += 1

    def dequeue(self):
        if self.size == 0:
            raise IndexError("buffer is empty")

        value = self.data[self.head]
        self.data[self.head] = None
        self.head = (self.head + 1) % self.capacity
        self.size -= 1
        return value
```

`size` помогает отличить пустой буфер от полного: в обоих состояниях `head` и `tail` могут совпадать.

Динамический кольцевой буфер при заполнении может выделить более крупный массив и скопировать элементы в логическом порядке, начиная с `head`.

# Дек

## Что это такое

Дек (`deque`, double-ended queue) — очередь с двумя концами. Добавлять и удалять можно как слева, так и справа.

```text
push_front -> [A] [B] [C] <- push_back
 pop_front <-           -> pop_back
```

Дек может вести себя:

- как стек, если работать с одним концом;
- как очередь, если добавлять с одного конца и извлекать с другого.

## Python collections.deque

```python
from collections import deque

items = deque([2, 3])

items.appendleft(1)  # [1, 2, 3]
items.append(4)      # [1, 2, 3, 4]

left = items.popleft()  # 1
right = items.pop()     # 4
```

Все четыре операции на концах выполняются за `O(1)`.

У `deque` есть индексирование, но доступ к середине не является его сильной стороной. Если нужен частый произвольный доступ по индексу, обычно лучше `list`.

## Дек на двусвязном списке

Если хранить `head` и `tail`, двусвязный список позволяет менять оба конца за `O(1)`.

Удобный приём — **сторожевые узлы**. Это пустые постоянные узлы по краям:

```text
head sentinel <-> A <-> B <-> tail sentinel
```

Даже пустой дек имеет структуру:

```text
head sentinel <-> tail sentinel
```

Благодаря этому большинство операций не требуют отдельных веток для первого или последнего настоящего элемента.

```python
class DequeNode:
    def __init__(self, data=None):
        self.data = data
        self.prev = None
        self.next = None


class LinkedDeque:
    def __init__(self):
        self.head = DequeNode()
        self.tail = DequeNode()
        self.head.next = self.tail
        self.tail.prev = self.head
        self.size = 0

    def appendleft(self, value):
        node = DequeNode(value)
        first = self.head.next

        node.prev = self.head
        node.next = first
        self.head.next = node
        first.prev = node
        self.size += 1

    def pop(self):
        if self.size == 0:
            raise IndexError("pop from empty deque")

        node = self.tail.prev
        previous = node.prev
        previous.next = self.tail
        self.tail.prev = previous
        self.size -= 1
        return node.data
```

Для полноценного дека аналогично добавляются `append`, `popleft` и просмотр крайних элементов.

## C++ std::deque и обычное слово «дек»

В лекции показан `std::deque`, который обычно организован не как один непрерывный массив и не как цепочка отдельных одиночных узлов, а как набор блоков фиксированного размера.

Это позволяет:

- добавлять с обоих концов;
- получать элемент по индексу за `O(1)`;
- не копировать всю коллекцию при каждом расширении одного из концов.

Не следует автоматически переносить все свойства C++ `std::deque` на любую структуру с названием deque. Например, Python `collections.deque` оптимизирован для концов, а доступ к середине не является `O(1)` в общем случае.

## Практический выбор в Python

| Задача | Структура |
|---|---|
| Стек | `list` или `deque` |
| FIFO-очередь | `collections.deque` |
| Дек | `collections.deque` |
| Потокобезопасная очередь между потоками | `queue.Queue` |
| Очередь с приоритетами | `heapq` или `queue.PriorityQueue` |
| Частый доступ по индексу | `list` |

Обычная очередь и очередь с приоритетами — разные структуры. В приоритетной очереди первым извлекается не самый старый элемент, а элемент с наивысшим приоритетом.

## Частые ошибки

### Ошибка 1: очередь через pop(0)

```python
value = items.pop(0)
```

Это `O(n)` из-за сдвига. Для очереди используй `deque.popleft()`.

### Ошибка 2: не проверить пустоту

`pop()` из пустой коллекции обычно вызывает исключение или возвращает специальное значение — поведение нужно определить явно.

### Ошибка 3: забыть обновить обе стороны связи

В двусвязном списке при вставке и удалении меняются и `next`, и `prev`.

### Ошибка 4: путать стек и очередь

Если добавить `A`, затем `B`, затем `C`:

- стек вернёт `C`;
- очередь вернёт `A`.

## Что важно запомнить

1. Стек работает по LIFO, очередь — по FIFO, дек — с обоих концов.
2. В Python стек удобно делать на `list`, используя его конец.
3. Для очереди и дека в Python обычно нужен `collections.deque`.
4. `list.pop(0)` и JavaScript `Array.shift()` могут требовать `O(n)`.
5. Кольцевой буфер позволяет реализовать очередь на массиве без постоянных сдвигов.
6. Одну абстрактную структуру можно реализовать разными способами с разными компромиссами.
