```python
def total(items):
    result = 0
    for item in items:
        result += item
    return result
```

```python
def has_duplicates(items):
    seen = set()

    for item in items:
        if item in seen:
            return True
        seen.add(item)
```

Укажи сложность по времени и дополнительной памяти.

## Практическая задача

Есть список товаров. Нужно узнать, существует ли товар с заданным `id`.

Вариант A — каждый раз проходить по списку:

```python
def find_product(products, product_id):
    for product in products:
        if product["id"] == product_id:
            return product
    return None
```

Вариант B — один раз построить словарь:

```python
products_by_id = {product["id"]: product for product in products}

product = products_by_id.get(product_id)
```

Ответь:

1. Какова цена построения словаря?
2. Какова средняя цена одного последующего поиска?
3. Когда вариант A может быть разумнее?
4. Когда вариант B явно выгоднее?

## Ответы

1. `O(1)` по времени и `O(1)` дополнительной памяти.
2. `O(n)` по времени и `O(1)` дополнительной памяти.
3. Два последовательных прохода — `O(2n)`, что сокращается до `O(n)`.
4. `O(n²)` по времени и `O(1)` дополнительной памяти, если не учитывать вывод.
5. В среднем `O(n)` по времени и `O(n)` дополнительной памяти для множества.

Для задачи с товарами:

1. Построение словаря — `O(n)` времени и `O(n)` дополнительной памяти.
2. Поиск по ключу словаря — в среднем `O(1)`.
3. Список может быть разумнее, если поиск выполняется один раз, данных очень мало или дополнительная структура не нужна.
4. Словарь выгоднее, если по одной и той же коллекции выполняется много поисков по `id`.
