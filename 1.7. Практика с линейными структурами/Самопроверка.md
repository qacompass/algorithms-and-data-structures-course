# Самопроверка к лекции 1.7

## Вопросы

1. Чем подпоследовательность отличается от подстроки?
2. Почему в решении двумя указателями индекс `candidate` двигается всегда, а индекс `source` — только при совпадении?
3. Какова дополнительная память решения подпоследовательности через очередь и через индексы?
4. Почему стек естественно подходит для палиндрома?
5. Зачем нужен фиктивный узел `dummy`?
6. Почему после удаления `current` нельзя всегда выполнять `previous = current`?

## Определи результат

```python
is_subsequence("ace", "abcde")
is_subsequence("aec", "abcde")
is_subsequence("", "abcde")
is_subsequence("aaa", "aa")
```

Ответы: `True`, `False`, `True`, `False`.

## Проследи палиндром

Для строки `"abca"` запиши `left`, `right` и сравниваемые символы на каждой итерации. На второй проверке будут сравнены `b` и `c`, после чего функция вернёт `False`.

## Практика

Измени проверку подпоследовательности так, чтобы она возвращала индексы найденных символов в `candidate`:

```python
def subsequence_positions(source, candidate):
    positions = []
    source_index = 0

    for candidate_index, character in enumerate(candidate):
        if (
            source_index < len(source)
            and source[source_index] == character
        ):
            positions.append(candidate_index)
            source_index += 1

    if source_index == len(source):
        return positions

    return None
```

```python
subsequence_positions("ace", "abcde")  # [0, 2, 4]
```

## Ответы

1. У подстроки символы идут подряд, у подпоследовательности между ними могут находиться другие символы.
2. Мы просматриваем всю большую строку, а в маленькой переходим к следующему ожиданию только после найденного совпадения.
3. Очередь требует `O(len(source))`, индексы — `O(1)`.
4. Стек возвращает символы в обратном порядке добавления.
5. Он создаёт предыдущий узел даже для головы и устраняет отдельную обработку удаления начала.
6. При удалении `previous` должен остаться на месте, чтобы проверить и при необходимости удалить следующий узел.
