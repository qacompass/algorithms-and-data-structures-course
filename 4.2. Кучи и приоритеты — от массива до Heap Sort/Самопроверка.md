## Индексы в массиве

Для узла с индексом `4`:

```text
parent = (4 - 1) // 2 = 1
left   = 2 * 4 + 1 = 9
right  = 2 * 4 + 2 = 10
```

Если индекс ребёнка не меньше длины массива, такого ребёнка нет.

## Проверь max-heap

```python
def is_max_heap(items):
    for parent in range(len(items) // 2):
        left = 2 * parent + 1
        right = 2 * parent + 2

        if left < len(items) and items[parent] < items[left]:
            return False

        if right < len(items) and items[parent] < items[right]:
            return False

    return True
```

Определи результаты:

```python
is_max_heap([10, 7, 9, 2, 3])  # True
is_max_heap([10, 12, 9])       # False
is_max_heap([])                # True
```

## Проследи вставку

Исходная max-heap:

```python
[21, 16, 18, 11, 6, 7, 12, 5]
```

Добавляем `20`:

```text
[21, 16, 18, 11, 6, 7, 12, 5, 20]
```

`20` сравнивается с родителем `11` и меняется с ним:

```text
[21, 16, 18, 20, 6, 7, 12, 5, 11]
```

Затем сравнивается с `16`:

```text
[21, 20, 18, 16, 6, 7, 12, 5, 11]
```

Корень `21` больше, подъём закончен.

## Практика 1. Очередь задач

```python
import heapq
from itertools import count


class PriorityTasks:
    def __init__(self):
        self._heap = []
        self._order = count()

    def add(self, priority, task):
        heapq.heappush(
            self._heap,
            (priority, next(self._order), task),
        )

    def pop(self):
        if not self._heap:
            raise IndexError("pop from empty queue")

        priority, _, task = heapq.heappop(self._heap)
        return priority, task
```

Меньшее значение `priority` обрабатывается раньше. Счётчик сохраняет порядок добавления при равных приоритетах.

## Практика 2. K ближайших значений к нулю

```python
import heapq


def closest_to_zero(numbers, k):
    return heapq.nsmallest(k, numbers, key=abs)
```

`key=abs` задаёт приоритет, но функция возвращает исходные числа.

## Ответы

1. Почти полная форма дерева и правило приоритета между родителем и детьми.
2. В max-heap родитель не меньше детей, в min-heap — не больше.
3. В корне, то есть на индексе `0` массива.
4. `2*i + 1` и `2*i + 2`.
5. Свойство кучи не определяет, в какой из ветвей находится произвольное значение.
6. `sift_up` поднимает вставленный элемент к родителям, `sift_down` опускает узел к более приоритетному ребёнку.
7. Большинство узлов находятся близко к листьям и требуют мало или ноль перестановок; дорогих узлов мало.
8. `O(n log n)` во всех основных случаях; классическая реализация неустойчива.
