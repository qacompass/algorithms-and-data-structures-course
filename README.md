# Алгоритмы и структуры данных

Практический курс для самостоятельного изучения алгоритмов и структур данных простым языком.

Материалы помогают не только запомнить названия алгоритмов, но и понять:

- зачем они нужны в реальной разработке;
- как устроены основные структуры данных;
- почему одни операции выполняются быстрее других;
- как оценивать время работы и расход памяти;
- как выбирать подходящее решение для конкретной задачи.

## Примеры на Python, но…

Основные примеры написаны на Python: его компактный синтаксис позволяет сосредоточиться на идее алгоритма, а не на служебных деталях языка.

Знать Python на продвинутом уровне не требуется. Если вы программируете на JavaScript, Java, C++, Go, C# или другом языке, примеры можно перенести на привычный синтаксис: сами алгоритмы и структуры данных от языка не зависят.

В некоторых конспектах отдельно объясняется, чем абстрактная структура из теории отличается от её реализации в Python или JavaScript. Например, классический массив и Python `list` связаны общей идеей, но устроены не одинаково.

## Для кого этот курс

- для начинающих разработчиков;
- для тех, кто уже умеет программировать, но плохо понимает алгоритмы;
- для подготовки к техническим собеседованиям;
- для систематизации знаний о сложности, поиске, сортировках и структурах данных;
- для перехода от запоминания решений к пониманию принципов.

## Как устроены материалы

Каждому занятию соответствует отдельная папка с двумя файлами:

- `Конспект.md` — подробное объяснение темы, примеры, оценки сложности и практическое применение;
- `Самопроверка.md` — вопросы, упражнения, небольшие задачи и ответы для проверки понимания.

Исходные учебные материалы и служебные PDF не входят в репозиторий. Репозиторий содержит самостоятельные текстовые конспекты и практику.

## Как проходить курс

1. Откройте `Конспект.md` соответствующей темы.
2. Запускайте примеры самостоятельно и меняйте входные данные.
3. Попробуйте объяснить алгоритм своими словами.
4. Пройдите `Самопроверка.md`, не заглядывая сразу в ответы.
5. Реализуйте основные алгоритмы самостоятельно.
6. После этого сравните решение с готовым примером и оцените его сложность.

Необязательно запоминать код дословно. Важнее уметь ответить на вопросы:

- какие данные поступают на вход;
- что происходит на каждом шаге;
- почему алгоритм выдаёт правильный результат;
- сколько времени и памяти ему требуется;
- при каких условиях решение перестанет работать.
