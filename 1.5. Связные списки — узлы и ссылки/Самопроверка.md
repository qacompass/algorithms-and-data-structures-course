## Вопросы

1. Почему встроенный Python `list` не является связным списком?
2. Что хранится в узле односвязного списка?
3. Почему нельзя получить сотый узел за `O(1)`?
4. Когда вставка в середину действительно имеет `O(1)`?
5. Зачем хранить `tail`?
6. Чем двусвязный список платит за возможность двигаться назад?
7. Почему при развороте сначала сохраняют `current.next`?
8. Почему в поиске цикла нужно сравнивать узлы, а не только данные?

## Проследи разворот вручную

Дан список:

```text
1 -> 2 -> 3 -> None
```

Для каждой итерации запиши значения:

- `previous`;
- `current`;
- `next_node`;
- новую ссылку `current.next`.

После первой итерации должно получиться:

```text
None <- 1    2 -> 3 -> None
        ^    ^
 previous current
```

## Практика 1: преобразование в обычный список

Напиши функцию, которая принимает голову связного списка и возвращает Python `list` с его данными.

```python
def to_list(head):
    result = []
    current = head

    while current is not None:
        result.append(current.data)
        current = current.next

    return result
```

- время — `O(n)`;
- дополнительная память — `O(n)` для результата.

## Практика 2: удалить первый найденный узел

```python
def remove_first(head, target):
    if head is None:
        return None

    if head.data == target:
        return head.next

    previous = head
    current = head.next

    while current is not None:
        if current.data == target:
            previous.next = current.next
            return head

        previous = current
        current = current.next

    return head
```

Подумай, почему удаление головы приходится обрабатывать отдельно.

## Практика 3: середина

Что вернёт функция из конспекта для списков:

```text
1 -> 2 -> 3 -> 4 -> 5 -> None
1 -> 2 -> 3 -> 4 -> 5 -> 6 -> None
```

В первом случае будет узел `3`, во втором — узел `4`, то есть второй из двух центральных.

## Ответы

1. Python `list` хранит ссылки в динамическом массиве и поддерживает прямой доступ по индексу.
2. Данные и ссылку на следующий узел; в двусвязном списке также ссылку на предыдущий.
3. Адрес сотого узла нельзя вычислить напрямую: нужно пройти цепочку от головы.
4. Когда ссылка на предыдущий или нужный узел уже известна и поиск не требуется.
5. Чтобы добавлять в конец за `O(1)`, не проходя весь список.
6. Дополнительной памятью и необходимостью обновлять больше ссылок.
7. После изменения `current.next` иначе потеряется путь к необработанной части списка.
8. Два разных узла могут содержать одинаковые данные; цикл определяется повторным попаданием в тот же объект-узел.

Голову обрабатывают отдельно, потому что перед ней нет предыдущего узла, ссылку которого можно переключить. При удалении головы меняется сама ссылка `head`.
