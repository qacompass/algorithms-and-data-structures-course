# Самопроверка к лекции 1.1

Сначала ответь самостоятельно, затем открой раздел с ответами.

## Вопросы

1. Чем алгоритм отличается от программы на Python?
2. Что является входом и выходом алгоритма поиска пользователя по `id`?
3. Почему для частого поиска пользователя по `id` словарь обычно удобнее списка?
4. Зачем нужен псевдокод?
5. Относится ли изучение алгоритмов к JavaScript и Python?

## Маленькое упражнение

Опиши словами алгоритм, который принимает список температур и возвращает количество значений выше нуля.

Затем сравни со следующим вариантом:

```python
def count_positive(temperatures):
    count = 0

    for temperature in temperatures:
        if temperature > 0:
            count += 1

    return count
```

Попробуй назвать:

- вход;
- основную операцию;
- условие завершения;
- выход.

## Ответы

1. Алгоритм — общая логика решения. Программа — запись этой логики на конкретном языке с соблюдением его синтаксиса.
2. Вход — коллекция пользователей и искомый `id`. Выход — найденный пользователь либо значение, означающее отсутствие результата.
3. В словаре `id` можно использовать как ключ. Не приходится каждый раз перебирать всех пользователей.
4. Чтобы описать решение независимо от синтаксиса языка и сосредоточиться на логике.
5. Да. Интерпретатор или движок скрывает часть деталей, но выполняет те же операции над данными.

В упражнении входом является `temperatures`, основной операцией — проверка `temperature > 0`, цикл заканчивается после просмотра всех значений, выходом является `count`.
