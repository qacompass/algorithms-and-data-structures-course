# 1.1. Что такое алгоритмы и структуры данных

## Самая короткая версия

**Алгоритм** — точная последовательность действий, которая превращает входные данные в нужный результат.

**Структура данных** — способ организовать данные так, чтобы с ними было удобно выполнять нужные операции.

Пример из обычного приложения:

- входные данные: список товаров и выбранная категория;
- структура данных: список объектов с товарами;
- алгоритм: пройти по товарам, оставить подходящие и отсортировать их по цене;
- результат: товары нужной категории в нужном порядке.

Алгоритмы — не особенность C++ или других компилируемых языков. Код на Python и JavaScript тоже состоит из алгоритмов и использует структуры данных. Различается только то, сколько технических деталей язык скрывает от программиста.

## Зачем это нужно обычному разработчику

Пока данных мало, почти любой работающий код кажется достаточно быстрым. Разница появляется при росте нагрузки.

Допустим, нужно для каждого пользователя найти его заказы:

```python
for user in users:
    for order in orders:
        if order["user_id"] == user["id"]:
            ...
```

Если пользователей 10, а заказов 100, проблем не будет. Если и тех и других сотни тысяч, вложенные циклы выполнят огромное количество сравнений.

Можно один раз построить словарь заказов по идентификатору пользователя, а затем получать нужные данные намного быстрее:

```python
orders_by_user = {}

for order in orders:
    user_id = order["user_id"]
    orders_by_user.setdefault(user_id, []).append(order)

for user in users:
    user_orders = orders_by_user.get(user["id"], [])
```

Знание структур данных помогает увидеть подобные решения.

## Из чего состоит алгоритм

У алгоритма обычно есть:

1. **Вход** — данные, которые мы получили.
2. **Последовательность действий** — что именно нужно сделать.
3. **Условия завершения** — алгоритм не должен работать бесконечно, если это не специальная постоянно работающая программа.
4. **Выход** — результат выполнения.

Пример:

```python
def find_min(numbers):
    if not numbers:
        return None

    minimum = numbers[0]

    for number in numbers[1:]:
        if number < minimum:
            minimum = number

    return minimum
```

- вход: `numbers`;
- действия: сравнить элементы с текущим минимумом;
- завершение: элементы списка закончились;
- выход: минимальное значение.

## Один алгоритм можно записать по-разному

В лекции упоминаются словесное описание, блок-схемы, псевдокод, язык программирования и машинный код. Это не разные алгоритмы, а разные способы показать одну и ту же последовательность действий.

### Словами

1. Запомнить первый элемент как текущий минимум.
2. Просмотреть оставшиеся элементы.
3. Если очередной элемент меньше, запомнить его.
4. Вернуть найденный минимум.

### Псевдокодом

```text
minimum = первый элемент

для каждого оставшегося элемента:
    если элемент меньше minimum:
        minimum = элемент

вернуть minimum
```

### На Python

```python
minimum = min(numbers)
```

Встроенная функция скрывает реализацию, но ей всё равно приходится определить минимальный элемент. Короткая запись не отменяет существование алгоритма.

## Что такое псевдокод

Псевдокод — запись логики без строгой привязки к синтаксису языка. Его не запускают. Он нужен, чтобы сначала понять решение, а затем перевести его на Python, JavaScript или другой язык.

Например:

```text
если список пуст:
    вернуть null

для каждого элемента списка:
    если элемент подходит:
        вернуть элемент

вернуть null
```

Не стоит искать у псевдокода точный синтаксис. Важно понять ветвления, циклы, данные и возвращаемый результат.

## Зачем в лекции машина Тьюринга

Машина Тьюринга — теоретическая модель вычислений: лента с ячейками, головка чтения и записи и набор строгих правил.

Для практической разработки сейчас достаточно понять одну мысль: сложное вычисление можно разложить на простые однозначные операции. Учить устройство машины Тьюринга наизусть для решения следующих задач курса не требуется.

## Что такое структура данных

Одинаковые значения можно организовать по-разному:

- `list` — когда важен порядок и нужен доступ по индексу;
- `dict` — когда значение нужно быстро получать по ключу;
- `set` — когда важно быстро проверять наличие и не нужны дубликаты;
- очередь — когда элементы обрабатываются в порядке поступления;
- стек — когда первым обрабатывается последний добавленный элемент.

Пример выбора:

```python
# Неудобно: каждый поиск требует прохода по списку.
users = [
    {"id": 101, "name": "Анна"},
    {"id": 205, "name": "Илья"},
]

# Удобно для поиска по id.
users_by_id = {
    101: {"id": 101, "name": "Анна"},
    205: {"id": 205, "name": "Илья"},
}

user = users_by_id.get(205)
```

Структура данных выбирается под частые операции, а не по принципу «какую структуру я лучше помню».

## Python и JavaScript здесь ничем не хуже

Python и JavaScript являются высокоуровневыми языками. Они автоматически управляют памятью и предоставляют готовые структуры данных. Поэтому мы реже видим адреса памяти, выделение блоков и освобождение ресурсов.

Но при выполнении:

```python
items.insert(0, value)
```

Python должен освободить место в начале списка и передвинуть существующие ссылки на элементы. А при выполнении:

```javascript
items.unshift(value);
```

аналогичную работу делает движок JavaScript. Удобный метод скрывает действия, но не делает их бесплатными.

## Где это применяется на практике

- выбор подходящего типа коллекции;
- обработка больших ответов API;
- работа с базами данных и индексами;
- кеширование результатов;
- оптимизация медленных участков;
- пагинация, сортировка, фильтрация и поиск;
- собеседования и задачи на алгоритмическое мышление;
- понимание работы стандартных библиотек.

## Что важно запомнить

1. Алгоритм — не код на конкретном языке, а логика решения.
2. Структура данных определяет, какие операции будут удобными и быстрыми.
3. Python и JavaScript скрывают память, но всё равно подчиняются тем же ограничениям компьютера.
4. Не нужно запоминать все определения дословно. Нужно научиться узнавать вход, действия, результат и цену этих действий.
